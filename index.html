Do Not Mix Them Up

度量、范数、内积：同一对象的三层信息

它们不是三个互不相关的公式，而是一条“信息逐渐增加”的链。

d(x,y)

度量：比较两个对象

只告诉你 x 与 y 相差多远。对象不一定能相加，所以一般不能写 x-y。

  • 能定义：邻域、连续、收敛
  • 例子：Hamming 距离
  • 不一定有：长度、角度
← 由 ∥x-y∥ 产生
∥x∥

范数：衡量单个对象

先衡量 x 的大小，再用 ∥x-y∥ 衡量差距，因此必须有线性结构。

  • 能定义：绝对误差、相对误差
  • 例子：1、2、∞ 范数
  • 不一定有：正交与投影
← 由 √(x,x) 产生
(x,y)

内积：比较方向关系

除了长度，还能判断两个方向是否正交，以及一个向量在另一个方向上的分量。

  • 能定义：角度、投影、正交
  • 例子：点积、积分内积
  • 直接支持：最小二乘逼近
记忆规则距离问“两个对象差多少”；范数问“一个对象有多大”；内积问“两个方向有多像”。

Worked Examples

四个分步例题，把定义变成操作

每题都按照“先判断对象—再选定义—最后解释结果”的顺序。

例 1
线性空间

判断一个集合是不是子空间

设 V={(x,y)∈ℝ² : x+y=0}。判断 V 是否为 ℝ² 的线性子空间。

  1. 检查零向量

    (0,0) 满足 0+0=0，所以零向量在 V 中。

  2. 检查加法封闭

    若 x₁+y₁=0、x₂+y₂=0，则 (x₁+x₂)+(y₁+y₂)=0。

  3. 检查数乘封闭

    若 x+y=0，则 αx+αy=α(x+y)=0。

结论 V 是子空间。它其实是一条过原点的直线，基可取 {(1,-1)}，维数为 1。

易错点：{x+y=1} 不是子空间，因为不含零向量；“看起来是一条直线”还不够，必须过原点并对运算封闭。

例 2
向量范数

同一个误差为何有三种大小

误差向量 e=(1,-2,2)。分别计算 ∥e∥₁、∥e∥₂、∥e∥∞。

  1. 累计误差

    ∥e∥₁=|1|+|-2|+|2|=5。

  2. 能量式误差

    ∥e∥₂=√(1²+(-2)²+2²)=3。

  3. 最坏分量误差

    ∥e∥∞=max{1,2,2}=2。

怎么选 要保证每个分量都不过界，用 ∞-范数；关心总偏差，用 1-范数；平方误差或几何长度常用 2-范数。

易错点：数值不同不表示互相矛盾。范数是在回答不同的误差评价问题。

例 3
正交化

手算一次 Gram-Schmidt

将 x₁=(1,1)、x₂=(1,0) 正交化。

  1. 保留第一个方向

    y₁=x₁=(1,1)，且 (y₁,y₁)=2。

  2. 求 x₂ 在 y₁ 上的投影

    projy₁x₂=[(x₂,y₁)/(y₁,y₁)]y₁=(1/2)(1,1)。

  3. 减掉已有方向

    y₂=x₂-projy₁x₂=(1/2,-1/2)。检验 (y₁,y₂)=0。

结果 {y₁,y₂} 与原向量组张成同一平面，但现在两方向正交。归一化后可得到标准正交基。

易错点：分母是 (y₁,y₁)，不是 ∥y₁∥；若写范数，分母应是 ∥y₁∥²。

例 4
矩阵稳定性

一个小扰动是否会破坏可逆性

已知 A 可逆、∥A⁻¹∥=4，并有 ∥C-A∥=0.1。判断 C 是否一定可逆并估计 ∥C⁻¹∥。

  1. 计算允许的扰动半径

    1/∥A⁻¹∥=1/4=0.25。

  2. 比较扰动

    0.1<0.25，满足讲义中的充分条件，因此 C 一定可逆。

  3. 代入上界

    ∥C⁻¹∥≤4/[1-4×0.1]=4/0.6=20/3。

解释 ∥A⁻¹∥ 越大，保证可逆所允许的扰动越小；这就是病态问题对数据敏感的前兆。

易错点：条件不满足时只能说“定理无法保证”，不能直接断言 C 不可逆。

Chapter 01

线性空间：先确定“允许怎样组合”

讲义 4–9

定义的核心

在数域 𝔽（通常是 ℝ 或 ℂ）上，一个集合 V 若对向量加法和数乘封闭，并满足交换、结合、分配、零元与逆元等规则，就构成线性空间。

αx + βy ∈ V，∀x,y∈V，α,β∈𝔽

通俗地说：关键不在对象长得像不像箭头，而在于它们能否稳定地做线性组合。向量、矩阵、多项式、连续函数都可以是“向量”。

线性无关

若 a₁x₁+⋯+aₙxₙ=0 只能推出所有系数都为 0，则 {xᵢ} 线性无关。

判断含义：没有一个元素能被其余元素线性表示；信息没有重复。

基与维数

一组既线性无关、又能表示空间内全部元素的向量称为基；基中元素个数是维数。

p(x)=a₀+a₁x+⋯+aₙxⁿ ⇒ dim Pₙ=n+1
有限维例子ℝⁿ、ℂⁿ、n×n 矩阵空间、次数不超过 n 的多项式 Pₙ
无限维例子连续函数空间 C[a,b]；任意有限个多项式都不能张成全部连续函数
为什么数值分析关心它？

数值方法常把无限维问题投影到有限维子空间：选基函数、求有限个系数，再用线性代数计算。有限元、谱方法和插值都从这里开始。

Chapter 02

度量与完备性：距离决定“趋近”的含义

讲义 11–13

度量 d(x,y) 的三条规则

  1. 可分辨d(x,y)≥0，且 d(x,y)=0 ⇔ x=y
  2. 对称d(x,y)=d(y,x)
  3. 三角不等式d(x,z)≤d(x,y)+d(y,z)

度量只回答“两个对象相差多远”，不要求对象能相加，也不要求距离来自坐标。

Hamming 距离

两个 0–1 串中不同位置的个数。适合编码与离散数据。

正数上的对数距离

d(x,y)=|log x−log y|，衡量相对尺度变化。

圆周距离

取两点沿圆周的较短弧长，体现空间的几何结构。

Cauchy 序列→完备空间

“内部越来越靠近”

对任意 ε>0，从某项开始，序列中任意两项的距离都小于 ε。这个定义不需要提前知道极限是谁。

∀ε>0，∃N，n>N,p∈ℕ ⇒ d(xₙ,xₙ₊ₚ)<ε

“极限仍在本空间”

若每个 Cauchy 序列都收敛到空间中的某个点，则空间完备。完备性防止迭代过程逼近一个“不属于当前空间”的对象。

补全的思想：把彼此差异趋于 0 的 Cauchy 序列视为同一个“新点”，即可把不完备的度量空间嵌入一个完备空间。实数可看作有理数的一种完备化。

Chapter 03

范数：给“大小”和“误差”一个尺度

讲义 15–20

范数公理

∥x∥≥0，且 ∥x∥=0 ⇔ x=0∥αx∥=|α|∥x∥∥x+y∥≤∥x∥+∥y∥

范数能生成距离：d(x,y)=∥x−y∥。

ℓ∞ 范数

∥x∥∞=maxᵢ |xᵢ|

只看最坏分量。适合控制最大误差。

ℓ₁ 范数

∥x∥₁=Σᵢ |xᵢ|

累计所有分量的绝对量。

ℓ₂ 范数

∥x∥₂=(Σᵢ |xᵢ|²)¹ᐟ²

欧氏长度；来自标准内积。

函数范数

∥f∥∞=max |f(x)|∥f∥₁=∫|f(x)|dx∥f∥₂=(∫|f(x)|²dx)¹ᐟ²

同一误差，不同视角

一个函数可能在很窄区域出现尖峰：最大范数认为误差很大，积分范数却可能认为总体误差较小。选范数就是选评价标准。

范数等价：有限维与无限维的分界

C₁∥x∥α ≤ ∥x∥β ≤ C₂∥x∥α　（C₁,C₂>0）

若两种范数等价，它们产生相同的收敛概念。在有限维空间中任意两个范数都等价；在无限维函数空间中一般不成立。

为什么讲义中的 fₘ(x)=((x−a)/L)ᵐ 能说明不等价？

它在右端点达到 1，因此 ∥fₘ∥∞=1；但随着 m 增大，函数的非零部分越来越集中，∥fₘ∥₁=L/(m+1)、∥fₘ∥₂=√(L/(2m+1)) 都趋于 0。于是不存在统一的正常数把这些范数双向夹住。

Banach 空间

完备的赋范线性空间。许多数值迭代的收敛证明都依赖：近似解构成 Cauchy 序列，而完备性保证极限仍是可接受的解。

Chapter 04

内积与正交：把“方向”引入误差分析

讲义 22–31

内积提供的额外信息

内积 (x,y) 满足正定性、共轭对称性与线性。它能定义长度和正交：

∥x∥=√(x,x)x ⟂ y ⇔ (x,y)=0

范数只知道“多长”，内积还知道两个方向的关系，因此可以讨论投影、最佳逼近和正交分解。

Cauchy–Schwarz

|(x,y)| ≤ ∥x∥∥y∥

它保证由内积定义的“夹角”合法，并直接导出范数的三角不等式。

函数内积

(f,g)=∫ₐᵇ f(x)ḡ(x)dx

复函数情形需要对第二个因子取共轭；实函数时共轭可省略。

非正交基→Gram–Schmidt→正交基

正交坐标为何更简单

若 x=Σaᵢxᵢ 且基向量两两正交，则每个系数都可独立求出：

aᵢ=(x,xᵢ)/(xᵢ,xᵢ)

没有交叉耦合；这就是投影公式。

Gram–Schmidt 做了什么

依次从新向量中减去它在已有方向上的投影：

yᵢ=xᵢ−Σⱼ<ᵢ [(xᵢ,yⱼ)/(yⱼ,yⱼ)]yⱼ

每一步都保持当前张成空间不变，同时让新方向与旧空间正交。

数值提醒：经典 Gram–Schmidt 在浮点运算中可能因舍入误差失去正交性；实际计算常用修正 Gram–Schmidt 或 Householder QR。

Orthogonal Polynomials

加权内积与正交多项式

权函数 ρ(x)>0 决定区间不同位置的重要程度。

(f,g)ρ=∫ₐᵇ ρ(x)f(x)g(x)dx
族权函数定义 / 递推关键性质
Legendre Pₙρ(x)=1(n+1)Pₙ₊₁=(2n+1)xPₙ−nPₙ₋₁在 [−1,1] 上等权正交
Chebyshev Tₙρ(x)=1/√(1−x²)Tₙ(x)=cos(n arccos x)零点适合构造稳定插值节点

为什么重要：正交多项式让逼近系数彼此解耦；合适的零点还能构造高精度求积和抑制插值端点振荡。

Chapter 05

矩阵范数：矩阵把向量放大多少

讲义 33–42
输入 x→A→输出 Ax

矩阵范数不仅要像向量范数一样衡量“大小”，还要与乘法相容：∥AB∥≤∥A∥∥B∥。这样才能连续估计多步运算中的误差传播。

Frobenius 范数

∥A∥F=(Σᵢⱼ |aᵢⱼ|²)¹ᐟ²

把矩阵全部元素排成长向量后取 2-范数。易计算，并满足次乘性。

诱导范数 / 算子范数

∥A∥=supₓ≠0 ∥Ax∥/∥x∥ = sup∥x∥=1 ∥Ax∥

它就是矩阵对单位向量的最大放大倍数，因此天然满足 ∥Ax∥≤∥A∥∥x∥。

常用诱导范数

∥A∥∞=最大绝对行和∥A∥₁=最大绝对列和∥A∥₂=√ρ(AᴴA)

Spectral Radius

谱半径是无法绕开的下界

谱半径 ρ(A)=max |λᵢ|。对任意矩阵范数都有：

ρ(A) ≤ ∥A∥

若 Ax=λx，那么在特征向量方向上，A 的放大倍数就是 |λ|；矩阵范数作为“最大放大”不可能比它小。

进一步，对任意 ε>0，总能选择一种诱导范数，使 ∥A∥≤ρ(A)+ε。这说明谱半径几乎是所有可能范数中最紧的尺度。

I

逆矩阵的存在性

若 ∥B∥<1，则 I+B 可逆，并且

∥(I+B)⁻¹∥ ≤ 1/(1−∥B∥)
II

可逆性对扰动的稳定

若 A 可逆且

∥C−A∥ < 1/∥A⁻¹∥

则 C 仍可逆，且 ∥C⁻¹∥≤∥A⁻¹∥/[1−∥A⁻¹∥∥C−A∥]。

这里已经接近条件数

∥A⁻¹∥ 大意味着允许的扰动半径很小；小改动就可能显著改变解。后续线性方程组的条件数 κ(A)=∥A∥∥A⁻¹∥ 正是对这种敏感性的量化。

Common Misconceptions

常见误区：一句话错在哪里

真正理解一个概念，往往体现在能否识别“看起来很像”的错误说法。

“只要能相加，就是线性空间。”

还需要数乘封闭，并满足零元、逆元、分配律等全部公理；同时必须说明标量域。

“Cauchy 序列一定收敛。”

只有在完备空间中才成立。在 ℚ 中逼近 √2 的有理序列是 Cauchy 序列，却没有有理极限。

“有限维中所有范数的数值都一样。”

有限维范数只是等价，意味着能被固定常数双向控制；具体数值一般不同。

“∥f∥₂=0 表示 f 每一点都为 0。”

在连续函数空间中可以这样推出；在一般 L² 空间中只能推出 f 几乎处处为 0。

“线性无关就等于正交。”

正交非零向量一定线性无关，但线性无关的向量可以有明显夹角，不必正交。

“Frobenius 范数就是矩阵 2-范数。”

前者是所有元素平方和的平方根；后者是最大奇异值。通常 ∥A∥₂≤∥A∥F，但不相等。

“谱半径就是矩阵的最大放大率。”

只有对正规矩阵的 2-范数等特殊情形才直接相等；一般最大放大由诱导范数描述。

“扰动定理的条件不满足，矩阵就不可逆。”

该条件是充分条件而非必要条件。不满足只代表这个定理不给结论。

  5. 内积引入角度、正交、投影与最佳逼近
  6. 矩阵范数控制算子放大、误差传播与扰动稳定性

自测问题

1. 为什么所有内积都能诱导范数，但并非所有范数都来自内积？

内积通过 ∥x∥=√(x,x) 自动满足范数公理；反过来，只有满足平行四边形恒等式的范数才能由某个内积诱导。

2. 有限维空间中范数等价意味着什么？

换一种范数会改变误差数值，却不会改变一个序列是否收敛；常数因子也可被统一控制。

3. 为什么诱导矩阵范数最适合分析误差传播？

因为它直接以最大放大倍数定义，并自动给出 ∥Ax∥≤∥A∥∥x∥ 和 ∥AB∥≤∥A∥∥B∥。

4. ∥B∥<1 为什么能保证 I+B 可逆？

若不可逆，则 −1 是 B 的特征值，因而 ρ(B)≥1；但 ρ(B)≤∥B∥<1，矛盾。也可由 Neumann 级数 (I+B)⁻¹=I−B+B²−⋯ 理解。
