Chapter 01

线性空间：先确定“允许怎样组合”

讲义 4–9

定义的核心

在数域 𝔽（通常是 ℝ 或 ℂ）上，一个集合 V 若对向量加法和数乘封闭，并满足交换、结合、分配、零元与逆元等规则，就构成线性空间。

αx + βy ∈ V，∀x,y∈V，α,β∈𝔽

通俗地说：关键不在对象长得像不像箭头，而在于它们能否稳定地做线性组合。向量、矩阵、多项式、连续函数都可以是“向量”。

线性无关

若 a₁x₁+⋯+aₙxₙ=0 只能推出所有系数都为 0，则 {xᵢ} 线性无关。

判断含义：没有一个元素能被其余元素线性表示；信息没有重复。

基与维数

一组既线性无关、又能表示空间内全部元素的向量称为基；基中元素个数是维数。

p(x)=a₀+a₁x+⋯+aₙxⁿ ⇒ dim Pₙ=n+1
有限维例子ℝⁿ、ℂⁿ、n×n 矩阵空间、次数不超过 n 的多项式 Pₙ
无限维例子连续函数空间 C[a,b]；任意有限个多项式都不能张成全部连续函数
为什么数值分析关心它？

数值方法常把无限维问题投影到有限维子空间：选基函数、求有限个系数，再用线性代数计算。有限元、谱方法和插值都从这里开始。

Chapter 02

度量与完备性：距离决定“趋近”的含义

讲义 11–13

度量 d(x,y) 的三条规则

  1. 可分辨d(x,y)≥0，且 d(x,y)=0 ⇔ x=y
  2. 对称d(x,y)=d(y,x)
  3. 三角不等式d(x,z)≤d(x,y)+d(y,z)

度量只回答“两个对象相差多远”，不要求对象能相加，也不要求距离来自坐标。

Hamming 距离

两个 0–1 串中不同位置的个数。适合编码与离散数据。

正数上的对数距离

d(x,y)=|log x−log y|，衡量相对尺度变化。

圆周距离

取两点沿圆周的较短弧长，体现空间的几何结构。

Cauchy 序列→完备空间

“内部越来越靠近”

对任意 ε>0，从某项开始，序列中任意两项的距离都小于 ε。这个定义不需要提前知道极限是谁。

∀ε>0，∃N，n>N,p∈ℕ ⇒ d(xₙ,xₙ₊ₚ)<ε

“极限仍在本空间”

若每个 Cauchy 序列都收敛到空间中的某个点，则空间完备。完备性防止迭代过程逼近一个“不属于当前空间”的对象。

补全的思想：把彼此差异趋于 0 的 Cauchy 序列视为同一个“新点”，即可把不完备的度量空间嵌入一个完备空间。实数可看作有理数的一种完备化。

Chapter 03

范数：给“大小”和“误差”一个尺度

讲义 15–20

范数公理

∥x∥≥0，且 ∥x∥=0 ⇔ x=0∥αx∥=|α|∥x∥∥x+y∥≤∥x∥+∥y∥

范数能生成距离：d(x,y)=∥x−y∥。

ℓ∞ 范数

∥x∥∞=maxᵢ |xᵢ|

只看最坏分量。适合控制最大误差。

ℓ₁ 范数

∥x∥₁=Σᵢ |xᵢ|

累计所有分量的绝对量。

ℓ₂ 范数

∥x∥₂=(Σᵢ |xᵢ|²)¹ᐟ²

欧氏长度；来自标准内积。

函数范数

∥f∥∞=max |f(x)|∥f∥₁=∫|f(x)|dx∥f∥₂=(∫|f(x)|²dx)¹ᐟ²

同一误差，不同视角

一个函数可能在很窄区域出现尖峰：最大范数认为误差很大，积分范数却可能认为总体误差较小。选范数就是选评价标准。

范数等价：有限维与无限维的分界

C₁∥x∥α ≤ ∥x∥β ≤ C₂∥x∥α　（C₁,C₂>0）

若两种范数等价，它们产生相同的收敛概念。在有限维空间中任意两个范数都等价；在无限维函数空间中一般不成立。

为什么讲义中的 fₘ(x)=((x−a)/L)ᵐ 能说明不等价？

它在右端点达到 1，因此 ∥fₘ∥∞=1；但随着 m 增大，函数的非零部分越来越集中，∥fₘ∥₁=L/(m+1)、∥fₘ∥₂=√(L/(2m+1)) 都趋于 0。于是不存在统一的正常数把这些范数双向夹住。

Banach 空间

完备的赋范线性空间。许多数值迭代的收敛证明都依赖：近似解构成 Cauchy 序列，而完备性保证极限仍是可接受的解。

Chapter 04

内积与正交：把“方向”引入误差分析

讲义 22–31

内积提供的额外信息

内积 (x,y) 满足正定性、共轭对称性与线性。它能定义长度和正交：

∥x∥=√(x,x)x ⟂ y ⇔ (x,y)=0

范数只知道“多长”，内积还知道两个方向的关系，因此可以讨论投影、最佳逼近和正交分解。

Cauchy–Schwarz

|(x,y)| ≤ ∥x∥∥y∥

它保证由内积定义的“夹角”合法，并直接导出范数的三角不等式。

函数内积

(f,g)=∫ₐᵇ f(x)ḡ(x)dx

复函数情形需要对第二个因子取共轭；实函数时共轭可省略。

非正交基→Gram–Schmidt→正交基

正交坐标为何更简单

若 x=Σaᵢxᵢ 且基向量两两正交，则每个系数都可独立求出：

aᵢ=(x,xᵢ)/(xᵢ,xᵢ)

没有交叉耦合；这就是投影公式。

Gram–Schmidt 做了什么

依次从新向量中减去它在已有方向上的投影：

yᵢ=xᵢ−Σⱼ<ᵢ [(xᵢ,yⱼ)/(yⱼ,yⱼ)]yⱼ

每一步都保持当前张成空间不变，同时让新方向与旧空间正交。

数值提醒：经典 Gram–Schmidt 在浮点运算中可能因舍入误差失去正交性；实际计算常用修正 Gram–Schmidt 或 Householder QR。

Orthogonal Polynomials

加权内积与正交多项式

权函数 ρ(x)>0 决定区间不同位置的重要程度。

(f,g)ρ=∫ₐᵇ ρ(x)f(x)g(x)dx
族权函数定义 / 递推关键性质
Legendre Pₙρ(x)=1(n+1)Pₙ₊₁=(2n+1)xPₙ−nPₙ₋₁在 [−1,1] 上等权正交
Chebyshev Tₙρ(x)=1/√(1−x²)Tₙ(x)=cos(n arccos x)零点适合构造稳定插值节点

为什么重要：正交多项式让逼近系数彼此解耦；合适的零点还能构造高精度求积和抑制插值端点振荡。

Chapter 05

矩阵范数：矩阵把向量放大多少

讲义 33–42
输入 x→A→输出 Ax

矩阵范数不仅要像向量范数一样衡量“大小”，还要与乘法相容：∥AB∥≤∥A∥∥B∥。这样才能连续估计多步运算中的误差传播。

Frobenius 范数

∥A∥F=(Σᵢⱼ |aᵢⱼ|²)¹ᐟ²

把矩阵全部元素排成长向量后取 2-范数。易计算，并满足次乘性。

诱导范数 / 算子范数

∥A∥=supₓ≠0 ∥Ax∥/∥x∥ = sup∥x∥=1 ∥Ax∥

它就是矩阵对单位向量的最大放大倍数，因此天然满足 ∥Ax∥≤∥A∥∥x∥。

常用诱导范数

∥A∥∞=最大绝对行和∥A∥₁=最大绝对列和∥A∥₂=√ρ(AᴴA)

Spectral Radius

谱半径是无法绕开的下界

谱半径 ρ(A)=max |λᵢ|。对任意矩阵范数都有：

ρ(A) ≤ ∥A∥

若 Ax=λx，那么在特征向量方向上，A 的放大倍数就是 |λ|；矩阵范数作为“最大放大”不可能比它小。

进一步，对任意 ε>0，总能选择一种诱导范数，使 ∥A∥≤ρ(A)+ε。这说明谱半径几乎是所有可能范数中最紧的尺度。

I

逆矩阵的存在性

若 ∥B∥<1，则 I+B 可逆，并且

∥(I+B)⁻¹∥ ≤ 1/(1−∥B∥)
II

可逆性对扰动的稳定

若 A 可逆且

∥C−A∥ < 1/∥A⁻¹∥

则 C 仍可逆，且 ∥C⁻¹∥≤∥A⁻¹∥/[1−∥A⁻¹∥∥C−A∥]。

这里已经接近条件数

∥A⁻¹∥ 大意味着允许的扰动半径很小；小改动就可能显著改变解。后续线性方程组的条件数 κ(A)=∥A∥∥A⁻¹∥ 正是对这种敏感性的量化。

自测问题

1. 为什么所有内积都能诱导范数，但并非所有范数都来自内积？

内积通过 ∥x∥=√(x,x) 自动满足范数公理；反过来，只有满足平行四边形恒等式的范数才能由某个内积诱导。

2. 有限维空间中范数等价意味着什么？

换一种范数会改变误差数值，却不会改变一个序列是否收敛；常数因子也可被统一控制。

3. 为什么诱导矩阵范数最适合分析误差传播？

因为它直接以最大放大倍数定义，并自动给出 ∥Ax∥≤∥A∥∥x∥ 和 ∥AB∥≤∥A∥∥B∥。

4. ∥B∥<1 为什么能保证 I+B 可逆？

若不可逆，则 −1 是 B 的特征值，因而 ρ(B)≥1；但 ρ(B)≤∥B∥<1，矛盾。也可由 Neumann 级数 (I+B)⁻¹=I−B+B²−⋯ 理解。
